# Stable user data directory (CARR-11 candidate)

Adopt platformdirs 4.10.0 (MIT, no runtime dependencies, Python >=3.10) instead of implementing Windows Known Folder and XDG resolution. Publisher source: https://github.com/tox-dev/platformdirs/tree/078bc61171e1a0cfbb3f210ff0fd30795a359664 ; publisher wheel and SHA256: https://pypi.org/project/platformdirs/4.10.0/ . The published universal wheel is 22.7 kB. The installed local library's four source files (__init__.py, api.py, unix.py, windows.py) and LICENSE match the Git blobs at the publisher commit (5/5). The wheel itself was not downloaded or re-hashed here. Preserve its MIT license when packaging. requirements-layout.lock is a component pin, not the application lock; merge the named pin into the existing reviewed uv resolver inputs (#39) and verify approved wheel bytes before installation.

`resolve_layout(install_root)` returns the canonical program and persistent-data directories without creating or deleting anything. Use a fixed, version-independent app name, no roaming and no app-author duplication. The expected normal Windows data location is `%LOCALAPPDATA%\Universal Research Library`; the normal Linux location is `$XDG_DATA_HOME/Universal Research Library` (or `~/.local/share/Universal Research Library`). The actual OS resolves the base directory. The installer and application must use the same name and per-user context; do not switch names after release without a migration. Never store research data under program files. Reject overlapping paths in either direction, including resolved links. The installer must recheck before file operations, use a separate installer-owned manifest, reject unsafe junction/reparse-point changes, and uninstall only program-owned files. This helper is not authorization for recursive deletion and is not race-safe against concurrent directory changes. Do not fall back silently to the current directory on failure. MSIX filesystem redirection, elevated installer context and actual Windows path behavior require separate acceptance.

Validation: `python -m pytest -q tests/packaging/test_runtime_layout.py` from carr-library; Linux Python 3.13.5, pytest 9.0.2, platformdirs 4.10.0, 8 PASS / 0 FAIL, 0.07 s. Actual upstream Unix and Windows classes used; Windows Known Folder lookup is simulated with local paths, not a Windows OS test. Tested Unicode/spaces, no creation, stable path across upgrades, preservation of existing synthetic library, overlap including symlink, relative/file rejection and non-roaming Windows logic. No installer, uninstall, Windows/NVDA or clean wheel install performed. CARR-01/09/10 to review/adopt API; CARR-12/13/15 to validate actual Windows and installer behavior. No application merge or release claim.
