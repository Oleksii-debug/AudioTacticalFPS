Private local FFmpeg runtime for Universal Research Library

This is the unmodified FFmpeg-Builds/BtbN Windows x64 LGPL shared build
ffmpeg-n9.0.2-982-g836df4e858-20261126, daily tag autobuild-2026-11-26-12-56.
The official FFmpeg download page links to this build provider. Every original
archive file is retained, including LICENSE.txt, headers and documentation.
FFmpeg runs as a separate executable; no FFmpeg DLL is loaded into Python.

The pinned archive, component hashes, source revisions and acquisition URLs
are recorded in provenance/source-lock.json. All supplied files are verified
before the executable directory is offered to the application. A missing or
changed runtime fails closed. No download or model acquisition happens during
startup or validation. User-selected external executables remain separate.

Exact FFmpeg source and the build-provider recipes are included in sources/.
Additional license texts, the original publisher checksum list and embedded
build configuration are retained. The dependency-source index records upstream
repository/revision declarations in the exact build recipes. It is provenance,
not a claim that every third-party dependency's corresponding source or every
transitive license obligation has been independently reproduced here. This
package is prepared for the owner's private installation. Do not present it as
a public redistribution clearance or publish private runtime bundles.

Supported codecs, filters and devices are discovered from the actual local
executable. This archive verification does not prove Windows execution, audio
quality, microphone/playback behavior, NVDA, neural music or voice inference.
The separate native Windows smoke must run with runtime egress blocked.
