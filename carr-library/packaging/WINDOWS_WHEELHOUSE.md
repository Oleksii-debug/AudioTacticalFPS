# Windows x64 / CPython 3.11 wheelhouse preflight (candidate)

Reuse upstream uv 0.10.0 (MIT/Apache-2.0, https://github.com/astral-sh/uv/tree/0ba432459aa4e84d793fd8cfc98d13cf619316bb) from PR #35 and packaging 25.0 (Apache-2.0/BSD-2-Clause, https://github.com/pypa/packaging/tree/f58537628042c7f29780b9d33f31597e7fc9d664) for PEP 508 root requirement parsing. Build tools only, not new application dependencies. Use reviewed, already available binaries; no automatic download or source build.

From carr-library, `python packaging/windows_wheelhouse.py approved-roots.in approved-wheelhouse windows.lock` resolves a hash-pinned Windows x64 / CPython 3.11 target using uv's existing resolver and hash-mode dry run. Supply one exact named version per line in the root requirements and a directory of approved wheels, with upstream provenance and hashes reviewed separately. Run in a network-disabled environment for stronger isolation. Do not use untrusted inputs or mutable wheelhouses; uv offline flags do not replace OS isolation, and hashes generated from local wheels are not independent proof of upstream authenticity. No source distribution builds or interpreter downloads. The output is a target resolution candidate, not an installer or a security approval. Existing locks are preserved.

## Evidence

`python -m unittest discover -s tests/packaging -p test_windows_wheelhouse.py -v` on Linux / CPython 3.13.5 / uv 0.10.0 / packaging 25.0: 7 tests passed, exit 0, 11.506 s. Actual uv subprocesses resolved a local distribution-provided pip 25.1.1 universal wheel (SHA256 20568e5d750393b2a331d6b261886cbe5d62aca3f54d49a39815b7474d34cd9c) and synthetic tagged transitive wheels. Windows-only dependency selected; Linux-only wheel, wrong Python ABI, absent dependency and direct root URL rejected; preexisting lock preserved. uv warned the host Python 3.11 interpreter was absent; it used 3.13.5 for build context, with builds disabled. Target tags were explicitly enforced in the negative cases. No Windows binary execution, actual installation or isolated network observation.
