# Embedded catalog metadata preview — candidate
No independent database, no new parser. Consume PR20 AssetSnapshot bytes after intake validation, in a separately approved parser sandbox. No automatic invocation, registration, identity matching, author attribution, page-label verification, rights decision, or source mutation. Hints remain unverified and require user confirmation; missing fields remain unknown. Do not use a filename or document text to infer authorship. A document-level language hint is not language detection. The adapter is not a sandbox or a complete metadata service.
