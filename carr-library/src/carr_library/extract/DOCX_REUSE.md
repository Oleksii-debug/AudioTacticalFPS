## Text omission corrections, 2026-11-26

The actual python-docx 1.2.0 text APIs silently omit smart tags, equations, ruby annotations, symbol glyphs, alternate-content branches, soft hyphens and bidirectional run wrappers. Generated DOCX regression packages reproduced shortened paragraphs and missing text in table cells or hyperlinks. The existing unsupported-body guard now rejects these structures before returning shortened records, matching expanded XML names independently of the source namespace prefixes. No alternate Word parser or new dependency was added.

Original nine DOCX tests plus twenty new regressions: **29 passed**, zero failed, on Linux Python 3.12.14 / python-docx 1.2.0 / pytest 9.0.2. Command from the assembled product root: `PYTHONPATH=src:. python -m pytest -q tests/extract/test_docx_ordered.py tests/extract/test_docx_omitted_content.py`. The new cases include actual OOXML packages, Unicode/hyperlink/whitespace compatibility, and python-docx's supported nonbreaking-hyphen behavior. Thirteen original omission cases and five additional hyphen/bidirectional cases failed before their corresponding fixes.

Public API, logical locators and review-required status are unchanged. Unsupported documents produce the existing explicit `ValueError`; this prevents silent loss, but does not make those structures readable or verify visual Word layout. Source originals remain untouched. Windows/NVDA and release acceptance are separate pending checks.
