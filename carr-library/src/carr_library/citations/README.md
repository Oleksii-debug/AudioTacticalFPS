## Boundary and golden traceability
- Unknown page: PDF without explicit PageLabels gives unverified physical locator; pypdf otherwise defaults to apparent Arabic numbering. Explicit PDF metadata labels are candidates only, not proof of printed page. Tests create real synthetic PDFs with pypdf and assert Roman/Arabic labels and unknown/default behavior. Partial/malformed metadata may yield fallback candidates; none are verified automatically.
- Unpaginated formats: Segment N, never PDF page N. Repeated printed labels stay disambiguated by physical index. Missing author shown explicitly as unknown. No fabricated ranges.
- Exact evidence: frozen identity, locator, raw SHA256, Unicode code point offsets, original slice and metadata snapshot. Reject identity, digest, quote and bounds mismatch and unverified OCR. Resolve returns raw context from same locator/revision, not a search in current text.
- Cross-page: ordered contiguous slices with no missing tail/interior or mixed edition/revision/metadata. Each individual anchor must be resolved against its authorized raw source before presentation. Do not concatenate and claim a single original raw string.
- Snapshot creation and verification flags must come from authorized storage/extraction; not trusted UI inputs. The in-memory dataclasses are not a database integrity or authorization boundary. CARR-05/08 must persist immutable anchors and citation metadata, check membership, revision and verified text in a transaction; CARR-10 must carry asset digest and explicit locator from intake. No persisted manual override/audit, confidence, full multi-page citation formatter or production More wiring yet.
