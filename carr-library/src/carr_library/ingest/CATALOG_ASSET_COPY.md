# Catalog-bound original inventory (candidate, CARR-10)

Addresses the two whole-library acceptance gaps reported by CARR-15 in PR31 comment 7192622668 (MIME/suffix drift and omitted unindexed catalog editions). Existing revision-only helper stays unchanged; this is a separate combined-snapshot boundary, not a storage schema or migration. Explicit all-workspaces consent includes registered but unassigned assets. Copies only catalog-registered originals, deduplicated by digest; all sealed revisions must match authoritative workspace/edition/asset; catalog MIME/size and filename must agree with original bytes. Uses existing RetainedAssets for hash verification and no-clobber publication. Returns deterministic immutable inventory entries for future outer manifest binding. No automatic deletion of incomplete destinations. Requires trusted stable private parents, cooperative guard, independently validated immutable combined database snapshot. Does not itself attest schema, FTS/evidence integrity, cryptographically authenticate the snapshot, or publish a complete bundle. Missing schema fails closed. Only PDF/TXT currently supported by retention; unsupported catalog formats block this copy rather than silently omit them.
