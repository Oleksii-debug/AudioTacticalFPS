## Handoff and boundaries
Evidence is a frozen transfer object. CARR-04/05 must resolve and authenticate historical source revision, verify asset identity/rights, preserve immutable metadata snapshot, and provide the selected workspace/topic rows under a transaction. This adapter checks scope, raw text SHA-256, exact Unicode slice, verified status, locator kind, duplicate IDs and printed-label state before formatting. It cannot establish source identity from a self-consistent but untrusted caller-supplied record; it is not a security boundary or persistence implementation. No I/O, network, schema or UI changes. TXT/Markdown preserve exact quotation in reversible JSON string encoding, Unicode readable, newline and control escapes explicit, notes separate, dynamically sized Markdown fences. RIS bibliography-only, generic type, no raw quote or note; rejects control/newline metadata, only verified printed labels included. External Zotero import not verified. CSV/BibTeX, cross-page anchors, topic hierarchy, workspace persistence, archived revision resolution, More/navigation, clipboard and Windows/NVDA remain pending. No gate closed.
