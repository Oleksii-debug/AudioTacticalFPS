MANDATORY SCOPE REVISION 2: # Scope revision 2 — Universal Research Library (mandatory, user-approved)
Carr is an initial optional collection, not a hardcoded author, corpus, or product limit. Maintain original citation accuracy requirements for ALL imported books, articles, documents and languages. Keep English UI as initial default. No dependency on Carr corpus for general release; separately track acceptance of actual Carr collection once lawfully supplied. Never require Carr metadata to import a book.
## Required user workflow
1. Create, rename, describe, archive and switch independent research libraries/workspaces; each has separate search scope. Import locally owned books/articles in batches, add manually entered original text/books, metadata and provenance, edit metadata without silently rewriting original source. One source can be assigned to multiple collections without duplicating bytes; remove membership without deleting source. Explicit destructive deletion and backups only.
2. Create nested topic/section hierarchy per workspace (rename, move, reorder, archive, reject cycles); tags and saved queries/filters; browse/filter by author/title/language/collection/edition. Collections organize sources; topics/sections organize research evidence. Workspace isolation is mandatory; global search is explicit opt-in. Cross-language material is allowed; exact quote remains original-language source.
3. Save a search hit as immutable evidence linked to workspace/topic, source edition, physical and verified printed page or unknown, offsets, content hash and revision; preserve exact text, notes, commentary, tags, source links and bookmarks separately. Edit notes, not source quotation. Support multiple topics per source, search inside a topic, organize evidence by section, create research outline. Citation remains resolvable after collection changes; deletion with referenced evidence must fail closed or preserve explicit tombstone, never silently retarget.
4. Export selected topic/section as Markdown/text and eventually RIS/BibTeX/CSV with citation, note and evidence separation; safe escaping. Backup and restore workspace/catalog/evidence with manifest, checksums, version and non-destructive import; no sharing private books by default.
5. Accessible English desktop UI: Library/Collections, Topics/Sections, Books, Search, Evidence/Notes, More, Copy citation, Export; keyboard-only and NVDA verified on Windows.
## Implementation strategy: REUSE_FIRST
Use standard library SQLite/FTS5, BM25, unicode61 and parameterized queries as core; do not reinvent index. Use pypdf or pypdfium2 for PDF text/page labels/rendering subject to API/license tests; Tesseract for local OCR; OCRmyPDF optional separate process only after dependencies/licenses validated. Evaluate python-docx, EPUB adapters and export libraries when needed. Zotero, calibre, Recoll, Paperless-ngx are reference architectures or optional separately installed integration; no code copying without exact license, pinned source and compatibility review. Consider Zotero interoperability via RIS/BibTeX instead of embedding application; use sentence-transformers only if local model/license/relevance benchmark warrants. No paid API. Prefer mature dependencies with pinned versions, dependency SBOM and notices; verify Windows/offline and fail gracefully.
## User-owned repository reuse
Inventory available projects through GitHub, inspect relevant source and LICENSE read-only; prioritize existing book ingestion, page/semantic reader, catalog, SQLite, OCR and provenance. Never copy private repository source into public repository without explicit publication authorization. Do not modify other repos. Public code only after license/provenance review; safe independently implemented interfaces and behavior are allowed. Keep evidence of evaluated versions, actual API test, compatibility and why adopted/rejected. Do not claim exhaustive internet search or integration without tests.
## Acceptance extensions
U1 persistent independent workspaces and CRUD, collections and source memberships; U2 nested topic sections, reparent/cycle prevention, notes/tags/saved queries; U3 source-anchored evidence, revision drift detection and isolation; U4 scoped FTS and exact source, multi-author multilingual imports; U5 export/backup restore with no citation drift, clean Windows installation and NVDA. Test two unrelated authors/workspaces with identical titles and passages, multiple memberships, Unicode, archive/delete semantics, cycles, re-open persistence, corruption/restore and no cross-workspace disclosure. General release must pass U1–U5 and original G gates except Carr-specific G6 tracked as collection acceptance, not blocker for generic release. Never mark release done without real non-Carr lawful fixtures and independent Windows acceptance.
## Ownership changes
CARR-02 catalog/collections and membership; CARR-05 persistence and migrations; CARR-08 research workspace/topic/note/evidence service + export (new namespace research/); CARR-06/07 scoped retrieval; CARR-09 all new UI flows; CARR-10 import/restore orchestration; CARR-04 immutable citations; CARR-03 multilingual extraction; CARR-11 packaging and SBOM; CARR-12–15 independent tests/security/accessibility/acceptance; CARR-01 contracts and coordination. Review manual candidate prototype in bootstrap/universal_* before rewriting. This revision supersedes old Carr-only language and any release gate that makes absent Carr books a global blocker. All prior safety and ownership constraints remain.
