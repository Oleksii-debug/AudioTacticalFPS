# Baseline contracts v0 (candidate)
## Data model
Work(work_id, author_id, title, source_role); Edition(edition_id, work_id, language, volume?, publisher?, year?, edition_label?); Asset(sha256, edition_id, media_type, private_local_path, rights_status); TextRevision(revision_id, asset_sha256, extraction_config, review_status); Page(revision_id, physical_index >=1, printed_label?, printed_label_verified, raw_text, raw_sha256); Passage(passage_id, edition_id, revision_id, ordered raw spans, normalized_index_text); Job(asset_sha, revision_id, state, checkpoint, retry, error); AuditEvent(actor, timestamp, target, reason, old/new hashes).

A span is (physical_index, start inclusive, end exclusive) into the raw immutable page string; offsets are Unicode code-point positions, never guessed from a normalized text index. The physical page index is one-based. A printed label is independent, nullable and may be Roman/Arabic/text; unknown must never become a verified printed page. Source revision and edition identities travel throughout the system. A published revision is complete and its index atomically consistent.

## Services
Catalog.register(asset, edition) -> registration status (existing hash is not a second file). Extractor.extract_page(asset, physical_index, config) -> raw text, blocks, warnings, provenance. Ingest.start/resume/cancel -> Job, progress events. Storage.publish_revision(revision, pages, passages) atomic; storage.search only active committed revisions. SearchRequest(query, retrieval_mode literal/thematic, result_mode short/thematic, filters, limit, cursor) -> SearchResponse(hits, next_cursor, warnings). SearchHit(passage_id, edition_id, revision_id, raw_spans, raw_quote, score, reason, citation_ref). Reader.more(hit_ref, revision_id) -> ordered original pages; mismatch fails closed. Citation.format(ref) -> exact bibliographic reference; unverified page labels explicitly marked, physical page fallback. UI delegates all operations to service APIs.

## Safety and implementation defaults
Local Python + SQLite/FTS5; choose GUI toolkit and OCR engine via ADR and verified accessibility/licensing; no mandatory external model or paid API. Originals immutable, sandbox untrusted parsers, no execution of document code, bounded resources, parameterized DB and query handling. Only synthetic fixtures in Git. Optional semantic embeddings must be offline and improve measured baseline. No invented quotations, no conflation of primary/secondary authors, no cross-edition page mapping, no silent correction of source text. Contract revisions require documented ADR and coordinator review.
