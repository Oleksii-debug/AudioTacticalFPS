# Трей і глобальні клавіші поточного читача

У Windows відкрийте потрібну книгу в читачі й натисніть **Tray and session hotkeys...**.
Функція керує саме цим вікном і його наявним озвученням. Вона не запускає
додатковий програвач або фоновий сервіс.

## Увімкнення

Початково іконка трея та глобальні клавіші вимкнені, а поля комбінацій порожні.

1. За потреби позначте **Show a tray icon for this reader**.
2. Для глобальних клавіш окремо позначте **Enable the following global hotkeys for this session**.
3. Введіть власні комбінації для потрібних дій. Порожнє поле лишає дію без глобальної клавіші.
4. Натисніть **Apply for this reader** і перевірте повідомлення про результат.

Допускається Ctrl разом з Alt або Shift та літерою A–Z, цифрою чи F1–F11.
Комбінації Windows, F12, звичайні клавіші редагування, повторення однієї комбінації
та конфлікти з поточною картою команд застосунку відхиляються. Якщо комбінацію
вже зайняла інша програма, виберіть іншу: застосунок не змінює її власника.
При частковому збої реєстрації вже надані цій спробі клавіші відкликаються.
Автоматичне повторення клавіші пригнічується через RegisterHotKey з MOD_NOREPEAT.

## Дії

- **Show this reader** повертає вибране вікно на передній план. Озвучення не починається.
- **Pause or resume voice reading** ставить на паузу або продовжує поточне озвучення цього читача.
- **Stop voice reading** зупиняє його поточну операцію через звичайне керування читача.

Ті самі дії доступні в меню іконки трея. В один момент лише один читач може
володіти цими засобами керування. Відкриття іншого читача не переносить керування
автоматично. Закрийте або вимкніть попередній сеанс, а тоді явно виберіть новий.

## Вимкнення і закриття

**Disable / retry cleanup** вимикає дії й звільняє їхні власні реєстрації та іконку.
Закриття вікна налаштувань залишає явно ввімкнений сеанс активним.
Закриття самого читача відкликає його обробники та звільняє ресурси.

Якщо Windows не підтвердить звільнення реєстрації, повідомлення прямо назве
очищення непідтвердженим. Дії вже не виконуються, але точний власник ресурсу
зберігається для повторної спроби. Інший читач не отримує цей сеанс мовчки.
Натисніть **Disable / retry cleanup**; якщо приймач нативних повідомлень уже
знищений, завершіть застосунок перед новим сеансом.

Налаштування сеансу не записуються на диск, не додають автозапуск і не залишають
процес після завершення застосунку. Повторний запуск починається з вимкнених
засобів керування. Це не режим приховування застосунку в трей при закритті.

## Межі перевірки

Переносний набір tests/ui/test_reader_background.py перевіряє дозволені
комбінації, єдиного власника, відкликання старих обробників, конфлікти,
часткове налаштування та утримання непідтвердженого очищення.

Для встановленої збірки Windows передбачено окремий запуск:

~~~powershell
& $installedPython -I -B -X utf8 scripts/windows_reader_session_smoke.py
~~~

Потрібні фактичне середовище Windows з робочим столом, установлені нативні
компоненти збірки та локальний голос SAPI. Скрипт перевіряє походження встановлених
модулів до й після роботи, реальну реєстрацію і конфлікт клавіш, іконку трея,
доставку WM_HOTKEY до власного приймача, фактичний синтез SAPI, керування чинним
читачем і закриття вікна без доступу пізніх обробників до знищених контролів.

У цьому скрипті WM_HOTKEY надсилається програмно до точного зареєстрованого
приймача. Відтворення PCM використовує вже наявний контрольований тестовий
пристрій із windows_live_reading_smoke.py; отриманий SAPI WAV справжній.
Це не доказ фізичного натискання глобальних клавіш, чутного звуку,
роботи конкретного аудіопристрою чи NVDA. Ці перевірки потребують окремого
фактичного запуску. Сам факт наявності скрипту не означає, що Windows-перевірка
вже завершилася успішно.
