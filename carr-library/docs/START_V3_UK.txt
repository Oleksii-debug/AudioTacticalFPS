1. ПЕРШИЙ ЗАПУСК

Якщо ви вже користувалися попередньою версією, спочатку відкрийте її
та створіть резервну копію бібліотеки. Зробіть це ДО першого запуску
нового ResearchLibrary.cmd: він може автоматично відкрити запам'ятовану
або типову папку даних і оновити структуру бази ще до вибору меню.

Залиште попередню програму в її папці. Вона може не відкрити вже
оновлену базу. Для повернення відновіть попередню резервну копію в нову
папку; не замінюйте нею робочі файли оновленої бібліотеки. Власні книжки
й дослідницькі дані зберігайте окремо від папки програми.

Завантажте один повний ZIP-архів із повідомлення. Він містить програму,
залежності, локальний пошук і OCR, ліцензії та супровідні джерела.
Додатковий архів Sources і об'єднання частин для цього комплекту не потрібні.
Необов'язкові аудіорушії підключаються окремо, як описано в розділі 5.

У Провіднику виділіть архів, натисніть Shift+F10 і виберіть «Видобути
все…». Видобудьте його в нову папку, у якій ви можете створювати файли.
Відкрийте внутрішню папку Universal-Research-Library.

Спочатку запустіть Install.cmd клавішею Enter. Дочекайтеся повідомлення
Installation complete. Після цього запускайте ResearchLibrary.cmd.
Окреме встановлення Python для цього комплекту не потрібне.
Установлення використовує файли з архіву; доступ до інтернету не потрібен.
Назва вікна — Resonance. Назви папки Universal-Research-Library і файлів
Install.cmd, ResearchLibrary.cmd та CheckInstallation.cmd збережено для
сумісності; їх не потрібно перейменовувати.

CheckInstallation.cmd перевіряє встановлення й показує результат у
текстовому вікні. Якщо перевірка повідомила помилку, збережіть її точний
текст. Не видаляйте папку дослідницьких даних під час перевстановлення.

Типове розташування даних: %LOCALAPPDATA%\Universal Research Library.
Для наявної бібліотеки використайте Library → Open existing library
folder. Програма запам'ятовує вибране розташування. Перейменування
продукту не переносить і не перейменовує ваші дані.

2. КЕРУВАННЯ З КЛАВІАТУРИ

Alt відкриває меню; стрілки переміщують вибір; Enter виконує команду.
Tab і Shift+Tab переміщують фокус між полями й кнопками. Space змінює
стан прапорця або вибраного пункту списку з прапорцями.

F1 відкриває клавіатурну довідку. Ctrl+I відкриває імпорт книжок.
Ctrl+R відкриває вибрану книжку для читання. Ctrl+Shift+B відкриває
академічну бібліотеку, Ctrl+Shift+L — Library tools. Ctrl+S зберігає
активну редаговану нотатку або проєкт у відповідному вікні.
Ctrl+Alt+P повідомляє стан поточної операції. Help → Keyboard shortcuts
(Ctrl+Alt+K) дозволяє налаштувати власні клавіші меню.

Це початкові поєднання клавіш. У вікні Reading Desk команда Ctrl+Shift+B
керує закладками, а Ctrl+Shift+L переводить фокус до поточної позиції
джерела та стану її перевірки. У Voice reader F6 починає читання,
F7 призупиняє або продовжує його, F8 зупиняє. У власних діалогах можуть
діяти окремі команди; їх наведено в довідці відповідного вікна.

Вікна використовують стандартні елементи Windows. Автоматичні перевірки
не замінюють окремого ручного проходження з NVDA: його результат для цієї
збірки не заявлено. Частина підписів інтерфейсу англійською; нижче наведено
точні назви основних меню.

ПРОГРЕС, СКАСУВАННЯ ТА ЗВУКОВІ ПІДКАЗКИ

Ctrl+Alt+P або Help → Current operation progress повідомляє стан
поточної операції, зокрема під час тривалої роботи. Автоматичні оновлення
не переводять фокус із поля, кнопки чи результату читання. Для кількох
вибраних файлів програма показує кількість отриманих результатів імпорту;
це не відсоток сторінок поточного PDF. Невідомий обсяг роботи залишається
невизначеним. 100% означає підтверджене завершення разом зі збереженням;
перевірка OCR, помилка та скасування мають окремі стани.

Cancel current operation надсилає запит на зупинку. Поточному компоненту
може знадобитися час, щоб підтвердити скасування. Уже збережені книги
залишаються в бібліотеці, наступні файли не імпортуються. Пізнє натискання
Cancel після збереження останнього файлу не скасовує успішний результат.
Перевірте підсумок із результатами для кожного файлу.

Help → Progress sound settings... відкриває налаштування:
Off; Beep; Speech: selected local voice; Beep + Speech.
Тут можна змінити інтервал, гучність і прапорці Quiet mode: mute progress
sound, Allow progress sound in the background та Mute progress sound
during playback (recording is always muted). Типове Off допомагає уникнути
подвійних сповіщень, коли стан уже озвучує NVDA. За типових налаштувань
підказки мовчать під час відтворення, під час запису — завжди; Quiet mode
вимикає їх повністю.

Для мовних підказок виберіть установлений голос у вікні читання або
Audio Studio й натисніть Use voice for progress. Голос діє в поточному
сеансі та бібліотеці; після зміни папки бібліотеки виберіть його знову.
Короткі підказки підтримують українську, англійську й словацьку; оберіть
голос відповідної мови. Це обмеження підказок не звужує мов, доступних
для читання через ваш установлений рушій. Зміна режиму не завантажує
і не встановлює голосів. Підказки не додаються до майстра, розділів
або окремих доріжок аудіопроєкту.

Ці можливості мають автоматичні Windows-перевірки. Статус саме цієї
збірки наведено в її звіті. Ручне проходження з NVDA та оцінка звучання
залишаються окремими перевірками.

3. БІБЛІОТЕКА Й РОБОТА З ДЖЕРЕЛАМИ

Library — бібліотеки, імпорт, черги, перевірка розпізнаних сторінок,
керування OCR-моделями та резервні копії.
Research — пошук, точні уривки, теми, дослідницькі нотатки й експорт.
Academic — бібліографія, списки читання, стилі цитування та метадані.
Reading і Voice — читання, закладки, установлені голоси та налаштування
озвучення. Convert — створення окремого тексту для зручного читання.

Для першої проби створіть бібліотеку через Library → New library,
імпортуйте власний документ через Import books і виберіть його в Books
and Collections. Звідси можна відкрити читання, змінити метадані або
використати Library tools для звіту каталогу й експорту бібліографії.
Вибрана бібліотека та колекція визначають область поточної операції.

Під час експорту бібліотечних, дослідницьких і бібліографічних даних
вибір наявного файла потребує окремого підтвердження; початкова
відповідь — «Ні». Якщо файл змінився, поки ви підтверджували заміщення
або програма готувала результат, експорт зупиняється, зберігаючи новіші
дані. Перегляньте цей файл і виберіть інше ім'я або знову виберіть його
та свідомо підтвердьте заміщення.

Для експорту окремого тексту копії для читання та аудіофайлів виберіть
нове ім'я: ці команди відхиляють наявну ціль.

Оригінальний документ, текст для зручного читання й дослідницькі нотатки
зберігаються окремо. OCR створює кандидат на розпізнаний текст. Його
потрібно перевірити в передбаченому програмою процесі перед використанням
як підтвердженого джерела. Нові метадані не переписують збережені раніше
цитати та їхню історію.

Копія для озвучення, створена з книжки, зберігає зв'язок із конкретним
джерелом і його позиціями. Цей зв'язок не надає копії статусу перевіреного
джерела цитат і не підтверджує точність OCR. Програма повторно перевіряє
доступ до джерела перед збереженням. Непов'язані текстові файли та проєкти
відкривайте в окремому вікні Voice reader, а не в копії вибраної книжки.

Для проєкту читання зі старішої попередньої збірки програма може показати
повідомлення про сумісність формату й вимагати Save As. Збережіть його
під новим ім'ям: старий файл і його чернетка залишаться на місці.
Відновлена чернетка не підмінює іншу вибрану книжку лише через однакову
назву або текст — має збігатися збережений зв'язок із джерелом.

У повному комплекті є локальний семантичний пошук і OCR для англійської,
української та словацької. Менеджер Fast/Best дозволяє перевірити й
установити додаткові офіційні моделі з наявної локальної папки. Він не
завантажує всі моделі автоматично. Каталог моделей не є перевіркою
точності розпізнавання кожної мови.

Використовуйте розпаковані файли, що відповідають вибраному Fast/Best
і точній ревізії каталогу: програма звіряє їхні контрольні суми.
Довільна новіша офіційна модель може не відповідати вибраному запису.

4. НОВИЙ ПОШУК DOI ТА ISBN

Відкрийте потрібну бібліотеку, потім Academic → DOI and ISBN lookup and
open-access sources… . Виберіть тип ідентифікатора та введіть DOI або ISBN.

DOI підтримує Crossref, Europe PMC, OpenAlex і додатково Unpaywall із
налаштованою контактною адресою. ISBN використовує Open Library.
Мережевий запит виконується після вашого явного дозволу. Програма не
надсилає провайдерам текст ваших книжок або приватні нотатки.
У режимі DOI контактна адреса передається лише Unpaywall, якщо ви
обрали цей сервіс. У режимі ISBN до Open Library передається ISBN;
контактна адреса та провайдери DOI в цьому запиті не використовуються.

Увімкніть у цьому діалозі прапорець дозволу онлайн-пошуку Allow online…
та натисніть Look up DOI або Look up ISBN, щоб виконати запит.

Перегляньте знайдену назву, авторів, рік, посилання й походження даних.
Save bibliographic reference зберігає бібліографічний запис. Apply
metadata to selected book застосовує вашу перевірену пропозицію до
книжки, вибраної перед відкриттям діалогу. Збережені раніше цитати
залишають свою початкову історію. Еквівалентні ISBN-10 та ISBN-13
враховуються під час пошуку дублікатів; неоднозначний збіг потребує
перевірки. Зміна вибору або бібліотеки може вимагати нового запиту.

Для отримання PDF відкрийте вкладку Download source, перегляньте
посилання, версію та ліцензію, виберіть колекцію й підтвердьте право
завантажити саме це джерело. Download selected PDF and import створює
нову папку результату та імпортує файл. Разом із ним зберігаються його
контрольна сума й відомості про джерело. Доступні тут лише PDF, для яких
провайдер заявив відкритий доступ. Така заява потребує вашої перевірки;
посилання лише для перегляду або позичання не дає дозволу на завантаження.

Доступність зовнішніх сервісів залежить від інтернету й самого сервісу.
Під час автоматичних перевірок використано контрольовані відповіді
провайдерів; успішне живе звернення кожного сервісу з цієї збірки не заявлено.

5. АУДІОСТУДІЯ Й АСИСТЕНТ

Для озвучення без додаткового аудіорушія відкрийте Voice → Voice reader
and reading copy (Ctrl+Alt+V). Виберіть реально встановлений голос Windows.
Цей окремий шлях читання й команда Save WAV не потребують FFmpeg; WAV
зберігається у форматі PCM. Наявність голосу потрібної мови залежить
від установлених у вашій Windows голосів.

Audio Studio — локальне озвучення сценарію, ролі, сцени, паузи, музика,
доріжки, розділи, субтитри та експорт. Студійне створення й обробка аудіо,
зокрема procedural music, потребують локальних FFmpeg і FFprobe навіть
для результату WAV. Ці два виконувані файли не входять до цього ZIP:
у проєкті ще не завершено перевірку їхнього пакета для передавання.

Якщо ви вже маєте власну довірену локальну інсталяцію, відкрийте
Audio Studio → Local voice and music engines. Кнопкою Choose FFmpeg
executable виберіть ffmpeg.exe, потім Choose FFprobe executable —
ffprobe.exe з тієї самої інсталяції. Вибір зберігається для поточної
бібліотеки. Після цього заново відкрийте вікно студії.

Для нового локального встановлення у Windows перевірена конфігурація
використовує Gyan FFmpeg 9.1 essentials. Сторінка видавця цього випуску:
https://github.com/GyanD/codexffmpeg/releases/tag/9.1
ZIP саме цього випуску можна отримати безпосередньо у видавця:
https://github.com/GyanD/codexffmpeg/releases/download/9.1/ffmpeg-9.1-essentials_build.zip
SHA256 цього ZIP:
b9bbbb3acece000cbeec994f856649354e52c773807841e78908374b24d658fd
Видобудьте його в окрему нову папку, збережіть LICENSE і README разом
із рушіями та виберіть файли ffmpeg.exe і ffprobe.exe з підпапки bin
описаними вище кнопками. Програма сама їх не завантажує. Іншу версію
не слід вважати перевіреною лише через збіг назви файла.

Для першої проби студії після підключення рушіїв виберіть реально
встановлений голос Windows, додайте короткий текст і нову папку результату.
Мова тексту має підтримуватися вибраним голосом.

Відкрийте Audio Studio → Script and audio production. У вікні студії
Render / resume (F6) запускає або продовжує завдання,
Pause (F8) просить його призупинити. Для продовження потрібні збережений
проєкт і вже створені фрагменти. Зберігайте проєкт перед тривалою роботою.
Після завершення перегляньте звіт і прослухайте результат.

Комплект містить потрібний локальний процесор бібліографії.
Процедурна музика не потребує нейромоделей, але використовує підключений
FFmpeg. Piper, MusicGen, ACE-Step та
інші додаткові рушії потребують сумісних локальних ресурсів і окремої
перевірки їхніх умов та фактичного звучання.

Якщо у вас уже є власна встановлена сумісна система dordiai-voices,
відкрийте Audio Studio → Local voice and music engines. У вікні Local
audio, voice and music engines виберіть Connect installed dordiai-voices,
вкажіть її папку kx47Runtime і підтвердьте запуск довіреного локального
рушія. Програма перевіряє передбачену контрактом структуру й ідентичність
робочого процесу. Приватний рушій, моделі й особисті голоси не входять
до цього ZIP і не завантажуються під час підключення.

Після підключення заново відкрийте Voice → Voice reader and reading copy
або Audio Studio → Script and audio production. Список наявних голосів
і мов завантажується у фоновому режимі. Disable dordiai-voices прибирає
збережений вибір, залишаючи встановлені файли й готові записи на місці.
Перевірена передача даних між програмою й адаптером не підтверджує
якість нейроголосів, вимову, схожість клону або підтримку всіх 135 мов.

Tools → Local assistant відкриває локального асистента, перегляд
запропонованих операцій, збережені завдання й дозволені папки.
Tools → AI and API connections керує необов'язковими профілями зовнішніх
провайдерів. Перевіряйте план перед виконанням дій із власними даними.

6. ПЕРЕКЛАД І ДОКУМЕНТИ

Tools → Translate selected text відкриває необов'язковий переклад через
Google Basic v2. Передавання вибраного тексту потребує окремого дозволу,

7. РЕЗЕРВНІ КОПІЇ

Library → Back up all libraries створює копію в новій папці. Збережіть
показану контрольну суму маніфесту окремо. Restore backup to a new folder
відновлює дані в іншу нову папку.

Копія охоплює базу, оригінали, нотатки, налаштування, проєкти й необхідні
дані незавершених імпортів. Готові аудіофайли, які ви зберегли поза папкою
даних, копіюйте окремо. Паролі з Windows Credential Manager на іншому
комп’ютері вводяться знову.
