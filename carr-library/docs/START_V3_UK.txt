ВСТАНОВЛЕННЯ Й ОНОВЛЕННЯ

1. Розпакуйте обидва ZIP: Application і комплект вихідних кодів OCR —
   в одну нову папку, щоб утворилася спільна Universal-Research-Library.
2. Поруч мають бути Install.cmd та ocr-corresponding-source.tar.
   Сам TAR не розпаковуйте: установник перевіряє його як частину комплекту.
3. Після повного розпакування обох ZIP відкрийте Install.cmd. Дочекайтеся
   Installation complete, потім запускайте ResearchLibrary.exe або
   ResearchLibrary.cmd. Не запускайте програму безпосередньо з архіву.

Основний комплект містить Python, залежності, пошукову модель,
процесор бібліографії та OCR українською, англійською й словацькою.
Його встановлення працює без завантаження залежностей. FFmpeg до архіву
для передачі не входить. Читання голосами Windows і WAV доступні без нього;
рендеринг Audio Studio потребує окремо встановлених FFmpeg і ffprobe.
Внутрішні назви ResearchLibrary і Universal Research Library збережені.

Перед оновленням зробіть резервну копію та закрийте стару програму.
Нове встановлення тримайте окремо від попереднього й особистих книжок.
Через Library → Open existing library folder відкрийте наявні дані.
Типове місце: %LOCALAPPDATA%\Universal Research Library.
Оновлену папку даних не відкривайте старою версією програми.

ІМПОРТ, ЧИТАННЯ Й OCR

Ctrl+I / Library → Import books: виберіть TXT, PDF, JPEG/JPG, PNG,
TIFF/TIF, DOCX, EPUB, HTML/HTM/XHTML, Markdown (.md/.markdown),
EML, FB2, FB3, ODT, ODS, ODP, PPTX або XLSX. Звичайна межа
одного оригіналу — 64 MiB. Для більших TXT/PDF є окремий потоковий
шлях до 128 MiB. Додатково діють обмеження розпакування, кількості
сторінок і логічних сегментів та видобутого тексту; потоковий шлях
не означає довільний розмір файла чи перетворення його вмісту.
Для папок і відновлюваних черг відкрийте Import Center: files, folders and queues.
Перегляньте план до запуску; змінені після планування файли виберіть повторно.
Після імпорту Ctrl+R відкриває Reading Desk, Ctrl+Shift+R — розділи EPUB.

Додаткові формати дають текст у логічному порядку, не точну копію макета.
Макроси й формули не виконуються; вкладення EML не стають текстом листа.
Оригінальні байти зберігаються. Видобутий текст не отримує автоматичного
підтвердження для цитування; логічний сегмент не є друкованою сторінкою.
Для сканованого PDF потрібні OCR та окрема перевірка розпізнаного тексту.
Менеджер OCR у Library дозволяє явно вибрати профіль Fast/Best і моделі;
нові моделі не завантажуються без вашої дії.

ПОШУК, ТЕМИ Й ЦИТАТИ

Research → Research Search Center (Ctrl+Alt+F) шукає у вибраних бібліотеках.
Доступні точна фраза, слова, тематичний і локальний семантичний пошук.
Для складних умов виберіть Advanced (AND, OR, NOT, NEAR);
Ctrl+Alt+Q відкриває конструктор. Оператори пишіть великими літерами:
  (пам'ять OR історія) AND NOT роман
  пам'ять NEAR/5 ідентичність
NEAR/5 допускає до п'яти слів між фразами; умови діють у межах сторінки
або текстового сегмента. Запит лише з NOT не дає джерельного свідчення.
Переглядайте контекст результату; копіювання підтвердженої цитати й
збереження її до теми доступні лише для перевіреного джерельного тексту.
Власні нотатки зберігаються окремо від цитат. Ctrl+Shift+F шукає
у збережених цитатах і нотатках; Ctrl+Shift+E експортує тему з підтемами.

АКАДЕМІЧНИЙ КАТАЛОГ І БІБЛІОГРАФІЯ

Ctrl+Shift+B у головному вікні відкриває Academic library: посилання,
теги, статус і прогрес читання, оцінки та особисті нотатки.
Import bibliography приймає локальні BibTeX, RIS і CSL JSON:
спочатку перегляньте записи, попередження й можливі дублікати.
Citation styles → Preview formatting формує бібліографію у семи стилях:
APA 7, Chicago 18 author-date, Chicago 18 notes and bibliography,
MLA 9, Harvard Cite Them Right 12, NLM/Vancouver та IEEE.
Доступний явний вибір локального незалежного CSL-файла.
Export bibliography зберігає текст, HTML або редагований Word (.docx).
Це звичайний документ із відомостями про цитування; додаток Word
з автоматичним оновленням полів у програму не входить.
DOI-запит потребує вашого дозволу; отримані метадані перевіряйте.

Експортуйте поза папкою даних. Заміна наявного файла потребує підтвердження;
якщо він змінився, виберіть його повторно. Якщо старий файл більший
за 32 MiB або перевірка вмісту перевищила відведений час, оберіть нове ім'я.
Це обмеження перевірки заміни, а не розміру нового експорту.

КЛАВІШІ Й ЗБЕРЕЖЕННЯ

Ctrl+Shift+P — Find a command; Ctrl+Alt+K — Keyboard shortcuts.
Ctrl+Shift+Q — Query current progress; F1 — клавіатурна довідка.
Ctrl+S — Save; Ctrl+Shift+S у головному вікні — Save all.
У Voice reader Ctrl+S зберігає читальну копію; у студії — проєкт.
У студії Ctrl+Shift+S означає Save as і експортує JSON проєкту.
У Reading Desk Ctrl+B додає закладку, Ctrl+Shift+B керує закладками.
Tab/Shift+Tab переміщують фокус. Options дозволяє змінювати клавіші
окремо для головного вікна й Reading Desk; наведені тут значення — типові.

ПРОГРЕС І СКАСУВАННЯ

Ctrl+Shift+Q працює під час операції. Оновлення прогресу не забирає фокус.
Для кількох файлів лічильник показує результати імпорту, не сторінки PDF.
За невідомого обсягу індикатор невизначений; 100% означає збережений результат.
Перевірка OCR, помилка та скасування мають окремі стани.
Cancel current operation запитує скасування; дочекайтеся підсумку.
Збережені книги залишаються. Наступні файли після скасування не імпортуються.
Пізнє Cancel після збереження останнього файла не скасовує успіх.

Options → Progress feedback settings: Off, Beep, Speech, Beep and speech,
гучність, інтервал, тихий режим і поведінка у фоні. Типово звук вимкнений.
Для Speech спочатку виберіть установлений голос у Voice reader або
Audio Studio та натисніть Use voice for progress. Це явний вибір на сеанс;
після зміни папки бібліотеки виберіть голос знову. Голос не завантажується.
Короткі підказки підтримують українську, англійську й словацьку;
мова має відповідати голосу. Інші голоси можуть залишатися для читання.
Off дозволяє користуватися повідомленнями NVDA без додаткового звуку.
Типово підказки мовчать під час відтворення; тихий режим вимикає їх.
Вони не додаються до майстра, розділів або доріжок аудіопроєкту.

ЛОКАЛЬНІ АУДІОКОМПОНЕНТИ ДЛЯ СТУДІЇ

Після Install.cmd відкрийте SetupLocalAudio.cmd. Спочатку він покаже
план; завантаження розпочинається лише після вашого явного підтвердження.
Потрібен інтернет для трьох зафіксованих публічних файлів. Підготовка
перевіряє розміри, SHA256 та склад файлів; моделі й голоси не завантажує.
Виберіть нову папку поза програмою й особистою бібліотекою. Існуючі
папки не перезаписуються, склад основного комплекту не змінюється.

Після успіху відкрийте Local audio, voice and music engines у програмі:
Choose FFmpeg executable — виберіть показаний runtime\bin\ffmpeg.exe;
Choose FFprobe executable — виберіть показаний runtime\bin\ffprobe.exe.
Повторно відкрийте Audio Studio. Налаштування належать вибраній бібліотеці.
Якщо ці компоненти вже встановлені, їх можна вибрати цими ж кнопками.
Без них основні бібліотечні функції залишаються доступними.

ПЕРШЕ ОЗВУЧЕННЯ

Після підключення аудіокомпонентів відкрийте Audio Studio, створіть проєкт
і виберіть установлений голос Windows.
Спробуйте короткий сценарій; різним персонажам можна призначити різні голоси:
  [Scene: Знахідка]
  Оповідач [center]: У читальній залі було тихо.
  [Pause: 2]
  Олена [left]: Я знайшла листа.
Виберіть нову папку результату, формат і Render: WAV-майстер, розділи,
обраний стиснений формат, доріжки, SRT/VTT і звіт. Pause зберігає завершені
фрагменти для продовження. Мова тексту має підтримуватися голосом.
Procedural створює просту локальну музику без моделей. Piper, MusicGen,
ACE-Step і приватні голоси потребують окремих сумісних файлів та перевірки.
Local audio, voice and music engines → Connect installed dordiai-voices
підключає вже встановлений приватний рушій після явного підтвердження.
Повторно відкрийте читання або студію для переліку його голосів і мов.

РЕЗЕРВНІ КОПІЇ Й МЕЖІ ПЕРЕВІРКИ

Після завершення чи зупинення роботи: Library → Back up all libraries.
Збережіть SHA256 маніфесту окремо. Копія охоплює бібліотеки, оригінали,
нотатки, налаштування, проєкти, завдання асистента та незавершені імпорти.
Відновлення створює нову папку; відновлені завдання запускайте явно.
Готове аудіо поза папкою даних копіюйте окремо. Секрети Windows Credential
Manager на іншому комп'ютері потрібно ввести знову.
Автоматичні й Windows-перевірки читайте у звіті саме цієї збірки.
Ручне приймання NVDA — NOT_RUN; якість голосів і моделей потребує прослуховування.
Каталог 135 мов не означає 135 перевірених голосів. Конкретні рушії
клонування й ASR потребують сумісних наданих файлів, прав на їх
використання та окремої перевірки якості. Підписаний EXE й довірені
підписані оновлення потребують справжньої особи видавця, підписів
і окремого приймання. Контрольні суми не є підписом видавця.


ОНОВЛЕННЯ КАНДИДАТА — 27.11.2026
Читач має окремі вкладки з відновленням, закладки в точній версії тексту,
поділ/об’єднання абзаців через Undo, явне візуальне читання та приблизне
стеження за виміряним аудіо. Приблизне стеження не є точними часовими
мітками слів від голосового рушія.

У Library додано Create incremental backup, Verify incremental backup chain
та Restore incremental backup to a new folder. Спершу створіть повну копію,
збережіть її SHA256 окремо й оберіть потрібні базові папки під час наступних
операцій. Інкрементальний шар містить змінені файли й потребує попередніх
копій. Відновлення створює нову бібліотеку та не запускає збережені рушії.

Профілі розпізнавання переглядаються й підтверджуються для конкретного
локального середовища. Пауза та скасування зберігаються; зміна або відновлення
середовища вимагає повторного перегляду. Точні поточні можливості й докази
описані в TRANSCRIPTION.md, TRANSCRIPTION_REVIEW_PROFILES.md та
V3_RELEASE_READINESS.md. Наявність коду або синтетичного тесту не підтверджує
якість конкретної моделі, приватного голосу чи ручну перевірку NVDA.
