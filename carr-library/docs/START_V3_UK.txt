Це бібліотека, робочі простори читання, аудіостудії й локальної транскрипції.
Для розпізнавання потрібні сумісний наданий рушій та локальні моделі.
Статус перевірок конкретного комплекту наведено в його звіті.
Підписаний випуск і повне приймання платформи залишаються окремими етапами.

ВСТАНОВЛЕННЯ Й ОНОВЛЕННЯ

1. Розпакуйте обидва ZIP: Application і комплект вихідних кодів OCR —
   в одну нову папку, щоб утворилася спільна Universal-Research-Library.
2. Поруч мають бути Install.cmd та ocr-corresponding-source.tar.
   Сам TAR не розпаковуйте: установник перевіряє його як частину комплекту.
3. Після повного розпакування обох ZIP відкрийте Install.cmd. Дочекайтеся
   Installation complete, потім запускайте ResearchLibrary.exe або
   ResearchLibrary.cmd. Не запускайте програму безпосередньо з архіву.

Основний комплект містить Python, залежності, пошукову модель,
процесор бібліографії та OCR українською, англійською й словацькою.
Його встановлення працює без завантаження залежностей. FFmpeg до архіву
для передачі не входить. Читання голосами Windows і WAV доступні без нього;
рендеринг Audio Studio потребує окремо встановлених FFmpeg і ffprobe.
Внутрішні назви ResearchLibrary і Universal Research Library збережені.

Перед оновленням зробіть резервну копію та закрийте стару програму.
Нове встановлення тримайте окремо від попереднього й особистих книжок.
Через Library → Open existing library folder відкрийте наявні дані.
Типове місце: %LOCALAPPDATA%\Universal Research Library.
Оновлену папку даних не відкривайте старою версією програми.

ІМПОРТ, ЧИТАННЯ Й OCR

Імпорт підтримує TXT, PDF, DOCX, EPUB та визначені текстові частини HTML,
Markdown, EML, FB2/FB3, ODT/ODS/ODP, PPTX і XLSX. Складне оформлення,
макроси та вбудовані програми не виконуються. Текст після видобування
потребує перевірки перед використанням як точної цитати.

Library: окремі бібліотеки, імпорт, черги, відновлення й резервні копії.
Research: пошук, точні цитати, теми, нотатки та експорт дослідження.
Academic: бібліографія та списки читання. Нові команди CSL формують
бібліографію у вибраному стилі та створюють редагований документ Word.
Імпорт BibTeX, RIS і CSL JSON спочатку показує записи для перевірки.
Заміна наявного експортованого файлу потребує вашого підтвердження.
Convert: перетворення вибраних документів на окремий текст для читання.
Похідний текст не замінює оригінал і не стає підтвердженою цитатою.
Audio Studio: озвучення сценарію з ролями, сценами, музикою, паузами,
окремими доріжками й субтитрами; локальні рушії та обробка аудіо.
Tools: локальний асистент, попередній перегляд операцій, збережені
завдання, дозволені папки й необов'язкові облікові записи провайдерів.
File → Save або Ctrl+S зберігає редаговану нотатку; в окремих вікнах
читання та студії ця сама команда зберігає відповідний проєкт.
Voice: читання, установлені голоси та пошук у затвердженому каталозі 135 мов.
Каталог показує перевірені можливості окремо від наявності ресурсів.
Library: менеджер OCR-моделей із явним вибором профілю та перевіркою файлів.
Help: клавіатурна довідка, власні клавіші меню та налаштування прогресу.
Ctrl+Alt+P повідомляє стан поточної операції. Звукові підказки типово вимкнені.
Tools → Translate selected text: необов’язковий Google Basic v2. Передавання вибраного
тексту потребує окремого підтвердження. Оригінал і переклад зберігаються
окремо; потрібні ваш власний обліковий запис, ключ і погоджений бюджет.

ЛОКАЛЬНА ТРАНСКРИПЦІЯ

Виберіть Library → Transcription: local audio and video... та натисніть
Підключити Whisper.
Оберіть сумісний профіль наданого рушія, його Python, worker.py та папку
вже встановлених моделей. Програма перевіряє вибрані файли.
Виберіть мову, модель, режим і потрібні формати, тоді Додати записи
або Додати папку з підпапками. Вкладені папки перевіряються автоматично;
підсумок показує збережені записи й виключені сторонні файли.

Запустити / продовжити запускає збережене завдання. Кнопка зупинки
залишає можливість продовжити його пізніше. Завершені результати
перевіряються перед прийманням; невдале або часткове завдання не
позначається завершеним. Редагування створює окрему похідну версію.
Оригінальні записи й первинний текст розпізнавання зберігаються.
Докладні інструкції та межі сумісності: docs/TRANSCRIPTION.md.

ПРОГРЕС І СКАСУВАННЯ

Ctrl+Shift+Q працює під час операції. Оновлення прогресу не забирає фокус.
Для кількох файлів лічильник показує результати імпорту, не сторінки PDF.
За невідомого обсягу індикатор невизначений; 100% означає збережений результат.
Перевірка OCR, помилка та скасування мають окремі стани.
Cancel current operation запитує скасування; дочекайтеся підсумку.
Збережені книги залишаються. Наступні файли після скасування не імпортуються.
Пізнє Cancel після збереження останнього файла не скасовує успіх.

Options → Progress feedback settings: Off, Beep, Speech, Beep and speech,
гучність, інтервал, тихий режим і поведінка у фоні. Типово звук вимкнений.
Для Speech спочатку виберіть установлений голос у Voice reader або
Audio Studio та натисніть Use voice for progress. Це явний вибір на сеанс;
після зміни папки бібліотеки виберіть голос знову. Голос не завантажується.
Короткі підказки підтримують українську, англійську й словацьку;
мова має відповідати голосу. Інші голоси можуть залишатися для читання.
Off дозволяє користуватися повідомленнями NVDA без додаткового звуку.
Типово підказки мовчать під час відтворення; тихий режим вимикає їх.
Вони не додаються до майстра, розділів або доріжок аудіопроєкту.

ЛОКАЛЬНІ АУДІОКОМПОНЕНТИ ДЛЯ СТУДІЇ

Після Install.cmd відкрийте SetupLocalAudio.cmd. Спочатку він покаже
план; завантаження розпочинається лише після вашого явного підтвердження.
Потрібен інтернет для трьох зафіксованих публічних файлів. Підготовка
перевіряє розміри, SHA256 та склад файлів; моделі й голоси не завантажує.
Виберіть нову папку поза програмою й особистою бібліотекою. Існуючі
папки не перезаписуються, склад основного комплекту не змінюється.

Після успіху відкрийте Local audio, voice and music engines у програмі:
Choose FFmpeg executable — виберіть показаний runtime\bin\ffmpeg.exe;
Choose FFprobe executable — виберіть показаний runtime\bin\ffprobe.exe.
Повторно відкрийте Audio Studio. Налаштування належать вибраній бібліотеці.
Якщо ці компоненти вже встановлені, їх можна вибрати цими ж кнопками.
Без них основні бібліотечні функції залишаються доступними.

ПЕРШЕ ОЗВУЧЕННЯ

Після підключення аудіокомпонентів відкрийте Audio Studio, створіть проєкт
і виберіть установлений голос Windows.
Спробуйте короткий сценарій; різним персонажам можна призначити різні голоси:
  [Scene: Знахідка]
  Оповідач [center]: У читальній залі було тихо.
  [Pause: 2]
  Олена [left]: Я знайшла листа.
Виберіть нову папку результату, формат і Render: WAV-майстер, розділи,
обраний стиснений формат, доріжки, SRT/VTT і звіт. Pause зберігає завершені
фрагменти для продовження. Мова тексту має підтримуватися голосом.
Procedural створює просту локальну музику без моделей. Piper, MusicGen,
ACE-Step і приватні голоси потребують окремих сумісних файлів та перевірки.
Local audio, voice and music engines → Connect installed dordiai-voices
підключає вже встановлений приватний рушій після явного підтвердження.
Повторно відкрийте читання або студію для переліку його голосів і мов.

РЕЗЕРВНІ КОПІЇ Й МЕЖІ ПЕРЕВІРКИ

Оберіть папку результату, формат і Render. Програма створює нову папку
з WAV-майстром, розділами, обраним стисненим форматом, окремими
доріжками, SRT/VTT і звітом. Pause зберігає завершені фрагменти;
після відкриття проєкту завдання можна продовжити. Якщо потрібно
різне звучання персонажів, призначте їм різні встановлені голоси.
Мова тексту повинна підтримуватися вибраним голосом.

Музика procedural створюється локально й працює без моделей. Це
простий інструментальний мотив. MusicGen, ACE-Step, Piper і сторонні
голоси потребують окремих сумісних локальних файлів і перевірки
їхніх умов використання. Комплект не завантажує їх автоматично.

ЩО САМЕ ПЕРЕВІРЕНО Й ЩО ПОТРЕБУЄ ОКРЕМОЇ ПЕРЕВІРКИ

Автоматичні перевірки охоплюють справжню базу даних, точність джерел,
відновлення, фактичне створення аудіо, формати документів та CSL.
Довгі файли тривалістю 1, 3 і 10 годин перевірені як потокове складання
з короткого згенерованого фрагмента й тестових пауз. Це не доказ
десятигодинної безперервної нейрогенерації музики.

Статус конкретної збірки та Windows-перевірок міститься в її звіті.
Ручне проходження з NVDA, прослуховування якості, конкретні сторонні
голоси й нейромоделі не підмінюються автоматичними тестами.
Word-експорт містить звичайний редагований текст, примітки та
ідентифікатори цитувань; це не встановлений додаток Word з автоматичним
оновленням полів. DOI-метадані потребують явного дозволу на запит і
залишаються пропозиціями для перевірки.

РЕЗЕРВНІ КОПІЇ

Library → Back up all libraries створює копію в новій папці та показує
SHA256 маніфесту. Збережіть контрольну суму окремо. Поточний спільний формат копії — 4; старі підтримувані формати читаються
за їхніми власними маніфестами. Копія містить базу,
оригінали, нотатки, налаштування, проєкти, закладки й позиції читання,
незавершені імпорти разом із потрібними вихідними файлами та збережені
завдання транскрипції з їхніми записами, результатами й правками.
Відновлення завжди створює нову папку й не запускає завдання автоматично.
Для відновленого проєкту Studio заново виберіть папку готового аудіо;
посилання на стару папку не дає дозволу записувати туди.
Зовнішні рушії та їхні моделі
потрібно підключити окремо на новому комп'ютері.
Окремо експортуйте й копіюйте готові аудіофайли, які збережено поза
папкою даних. Паролі з Windows Credential Manager не переносяться
звичайним експортом профілів; на іншому комп'ютері їх слід увести знову.

Комплект призначений для вашого приватного користування. Власні
книжки, облікові дані, сторонні голоси й аудіозаписи не публікуються.

СТАТУС ДОДАТКОВОГО ЗАХИСТУ Й ОНОВЛЕНЬ

Цей приватний комплект використовує перевірку цілісності й контрольні суми.
ResearchLibrary.exe є нативним запускником, але ще не має підпису видавця.
Комплект не активує приватний сервіс ліцензій
та підписаним оновленням. Ці частини потребують сумісного приватного
компонента, ключів довіри й окремих наскрізних перевірок. Власні бібліотеки,
резервні копії та експорт залишаються доступними. Клонування вашого голосу
потребує наданого й перевіреного локального рушія та дозволених зразків.
