ВСТАНОВЛЕННЯ Й НАЯВНІ ДАНІ

Для підготовленого автономного комплекту дотримуйтеся його інструкції
встановлення й перевірки цілісності. Зберігайте всі передбачені частини,
ліцензії та відповідні вихідні коди OCR. Не запускайте програму з ZIP.
Внутрішні назви ResearchLibrary.exe / ResearchLibrary.cmd збережені.

Перед оновленням збережіть роботу й перевірену резервну копію. Бібліотека
живе окремо від програмних файлів. Через Library → Open existing library
folder вибирайте саме наявну папку даних; це не команда створення іншої
порожньої бібліотеки. Відновлення копії завжди потребує нової папки.
Оновлені дані не слід відкривати старим неперевіреним комплектом.

Основна локальна робота не потребує хмарного розпізнавання чи синтезу.
Встановлення додаткових моделей, зовнішній переклад, пошук і перевірка
оновлень мають власні явні налаштування. Приховане завантаження моделі
або заміна вибраного голосу іншим не є припустимим обходом помилки.

БІБЛІОТЕКА, ОРИГІНАЛИ Й ВЕЛИКІ ФАЙЛИ

Library → Import books / Ctrl+I відкриває звичайний імпорт.
Import Center: files, folders and queues — відновлювані черги й папки.
Перед виконанням перегляньте джерела та обсяг. Якщо файл змінився,
виберіть його знову. Ctrl+R відкриває Reading Desk.

Прямі читачі підтримують TXT, PDF, DOCX, EPUB, HTML/HTM/XHTML,
Markdown, EML, FB2/FB3, ODT/ODS/ODP, PPTX та XLSX. Додаткові формати
залежать від явно вибраного сумісного конвертера. Наявність адаптера
не гарантує підтримки кожного старого різновиду формату.

Звичайна межа джерела — 64 MiB. Великі TXT/PDF мають окремі профілі
й числовий вибір дозволеного обсягу; це не загальне вимкнення перевірок.
Профіль до 4 GiB має також власні обмеження сторінок, тексту, диска й часу.
Дозволена межа не є обіцянкою виміряної швидкості для будь-якого файла.

Оригінальні байти зберігаються. Текст після OCR, конвертації, перекладу
або редагування не стає автоматично перевіреною цитатою. Логічний сегмент
не є друкованою сторінкою. Для цитування потрібні належне джерело,
точний контекст і, де потрібно, окрема перевірка розпізнаного тексту.

ПОШУК, НОТАТКИ Й БІБЛІОГРАФІЯ

Research Search Center / Ctrl+Alt+F шукає у вибраних бібліотеках.
Для складних умов використовуйте Advanced та конструктор Ctrl+Alt+Q.
Оператори AND, OR, NOT, NEAR задають умови пошуку; переглядайте джерельний
контекст перед копіюванням. Нотатки залишаються окремими від цитат.

Academic library / Ctrl+Shift+B у головному вікні відкриває каталог.
Локальні BibTeX, RIS та CSL JSON спочатку переглядаються, включно
з попередженнями й можливими дублями. Citation styles дає попередній
перегляд і явний вибір локального CSL. Експорт підтримує текст, HTML
і редагований DOCX. Зазначення автора citeproc-js залишається видимим.

Експортуйте поза папкою даних. Заміна існуючого файла потребує поточного
підтвердження його стану; якщо він змінився, перегляньте вибір повторно.
Редагована читальна копія, переклад і наукова нотатка не переписують
утриманий оригінал.

ЗБЕРЕЖЕННЯ, КЛАВІШІ Й ЗАВДАННЯ

Ctrl+S зберігає поточні зміни. Ctrl+Shift+S у головному вікні — Save all;
у редакторі чи Audio Studio це може бути контекстне Save as.
Використовуйте Find a command / Ctrl+Shift+P, Keyboard shortcuts та F1,
щоб переглянути актуальні призначення. Tab і Shift+Tab переміщують фокус.

Save all чекає підтвердження прийнятих операцій. Якщо запуск збереження
відхилено, чернетка має залишитися доступною, а операція — повідомити
про відмову. Не вважайте закрите вікно доказом успішного збереження.

Tools → Tasks and resources показує поточні підтримувані операції,
відновлення та спільні обмеження ресурсів. Пауза чи скасування потребують
підтвердження завершення власного процесу. Уже прийняті результати
залишаються збереженими. Прогрес не повинен забирати фокус або
домішувати звукові підказки до аудіомайстра.

АУДІОКОМПОНЕНТИ ТА ВЛАСНІ РУШІЇ

SetupLocalAudio.cmd показує план окремої підготовки FFmpeg 9.1 FULL.
Потрібні явне підтвердження, точний перевірений архів і нова зовнішня
папка. Можна використати вже завантажений відповідний архів.
Підготовка не встановлює голосів і моделей та не змінює бібліотеку.

Після перевірки відкрийте Audio Studio → Production →
Choose FFmpeg executable і виберіть показаний runtime\ffmpeg.exe.
Залишайте ffprobe, ліцензії та решту перевіреного каталогу поруч.
Деталі й контрольна сума: LOCAL_AUDIO_SETUP.md.

Tools → Local engine profiles підключає вже встановлені сумісні рушії.
Choose and review manifest перевіряє явно вибраний маніфест; Save reviewed
registration зберігає перевірену реєстрацію. Перед роботою файли знову
перевіряються. Копія старого шляху не є дозволом запуску.

Голоси Windows, Piper, dordiai-voices та музичні адаптери мають власні
можливості й обмеження. Для приватного клонування потрібні сумісний
рушій, модель і належні права на зразки. Каталог 135 мов не означає
135 перевірених голосів. SAPI4 не слід вважати доступним без окремо
перевіреної сумісної конфігурації.

СТУДІЯ, КНИГИ Й ЧЕРГА ВІДТВОРЕННЯ

Audio → Open Audio Studio / Ctrl+Alt+A відкриває наявну студію.
Виберіть голос і мову, введіть текст або передайте читальну копію,
задайте місце результату, перегляньте план, потім Render / resume.

Типово діє Literal narration: заголовки, двокрапки й квадратні дужки
залишаються текстом для озвучення. Structured production script потрібно
вибрати явно. Його точний синтаксис описано в AUDIO_STUDIO_V3.md;
довільні команди оболонки або вирази FFmpeg не виконуються.

Audio → Review multiple books for audio дозволяє вибрати й упорядкувати
книги, межі частин, назви та параметри. Спочатку перегляньте план і
призначення. Для вже прийнятого WAV/RF64 доступний окремий перегляд
поділу за виміряними PCM-кадрами, публікація та перевірка результату.
Такий поділ не потребує повторного синтезу. Межі слова не вгадуються,
якщо точного вирівнювання немає.

Керування темпом, висотою, гучністю й балансом залишається незалежним.
Збережена черга містить власні копії потрібного PCM. Restore saved queue
відновлює її зупиненою; Resume saved position потребує явної дії та
поточного виходу. Історична координата відрізняється від позиції,
підтвердженої фактичним відтворенням.

Import previous playback queue переглядає збережену канонічну чергу
або утриманий історичний архів і створює новий керований проєкт.
Оригінальні метадані та записи залишаються збереженими. Старий пристрій,
гучність, таймер чи автоматичне відтворення не активуються. Непідтриманий
формат потребує явного конвертування, а не мовчазної зміни оригіналу.

Якщо публікація вже відбулася, але завершальне прибирання не вдалося,
збережіть показаний ідентифікатор і перевірте наявний результат.
Повідомлення про таку ситуацію не є вказівкою створювати дубль.

ТРАНСКРИПЦІЯ

Tools → Local speech transcription використовує наданий власником
локальний worker через його чинний протокол. Публічний код не містить
приватного worker, записів, транскриптів, середовища чи ваг моделі.

Choose runtime manifest вибирає перевірений локальний маніфест;
Pick saved runtime використовує явно збережену локальну реєстрацію.
Додайте потрібні файли або папку, перегляньте мову, модель, пристрій,
паралельність та формати TXT/SRT/VTT/JSON. Prepare утримує точну вибірку
і фіксує параметри; Start / Resume — окрема дія.

Pause, Cancel та закриття чекають завершення власної операції.
Після відновлення даних старі шляхи не запускаються автоматично.
Готовий перевірений текст можна читати без повторної інференції.
Для іншого worker або несумісних параметрів потрібне нове завдання.
Розпізнавання не надає текстові повноважень підтвердженої цитати.

ПЕРЕКЛАД І АСИСТЕНТ

Структурований переклад працює з вибраним документом, розділом,
діапазоном або пакетом. Google Basic v2, Advanced v3 і явно вибраний
локальний адаптер мають різні налаштування. Для зовнішньої передачі
потрібні поточний дозвіл і бюджет. Наявність локального клієнта не
означає, що перекладацький сервер або модель вже встановлені.

Tools → Local assistant / Ctrl+Alt+J використовує ті самі служби.
Виберіть поточну бібліотеку та дозволені папки, перегляньте повний план
і окремо запустіть його. Пропозиція локальної моделі не є дозволом
довільно читати файли, виконувати код чи звертатися до мережі.

Іменовані шаблони зберігають інструкції. Після завантаження потрібні
нова область роботи й перегляд. Розклад діє лише після явного
увімкнення у відкритому вікні; це не прихований фоновий системний
сервіс. Завершене завдання спочатку перевіряється і не повторюється
лише через повторне відкриття.

РЕЗЕРВНІ КОПІЇ Й ПРИЙМАННЯ

Library → Back up all libraries створює перевірену копію.
Збережіть SHA-256 маніфесту окремо. Відновлення перевіряє схему, байти
та зв'язки з джерелами й публікує нову папку.

Підтримувані типізовані складові охоплюють каталог, оригінали,
нотатки, читальні копії, чернетки, керовані аудіопроєкти й черги,
завдання асистента, транскрипції, переклади та незавершені імпорти.
Точний склад визначає маніфест, а не назва архіву. Старі формати
не можуть відновити те, чого вони ніколи не зберігали.

Готові результати поза керованою бібліотекою копіюйте окремо.
Виконувані рушії, ваги моделей і секрети не є автоматично переносними.
Відновлені завдання, шаблони й історичні дані залишаються неактивними,
доки ви явно не переглянете поточні умови запуску.

Повний опис: COMPLETE_BACKUP.md, MANAGED_PLAYBACK_QUEUE.md,
LEGACY_PLAYBACK_QUEUE_MIGRATION.md, SUPPLIED_TRANSCRIPTION_BACKUP.md.
Статус інтеграції та фактичних перевірок:
V3_FINITE_GAP_AUDIT_2026_11_27.md і docs/acceptance у репозиторії.
Ручна перевірка NVDA, фізичних пристроїв, якості вибраних моделей,
мов, підпису видавця й прав на розповсюдження має окремі результати.
