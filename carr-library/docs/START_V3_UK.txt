РЕЗОНАНС / RESONANCE — ПОЧАТОК РОБОТИ
Sceneria Innovative Technologies
Інтегрована тестова збірка бібліотеки, читання та аудіо. 27 листопада 2026 року.

МЕЖІ ЦІЄЇ ЗБІРКИ

Це тестова бібліотечно-аудіальна частина платформи. Вона не означає
завершення всього технічного проєкту Resonance. Наданий код транскрипції
V4.3 отримано й переглянуто; додано підключення локального рушія,
збережені завдання та експорт. Перевірка з реальною моделлю й
якість розпізнавання залишаються окремою роботою. Так само окремо перевіряються
власні рушії клонування голосу, якість кожної мови, Windows 11/NVDA,
підписаний випуск та оновлення.

ВСТАНОВЛЕННЯ

1. Розпакуйте Application ZIP і Sources ZIP в одну нову папку.
   Збережіть обидва архіви. Окремий Sources ZIP містить супровідні
   вихідні матеріали OCR, на які посилається перевірка пакета.
2. Відкрийте Install.cmd. Установка перевіряє файли й використовує
   вкладені залежності; не запускає автоматичного завантаження моделей.
3. Після повідомлення про успішне завершення відкрийте ResearchLibrary.exe.
   Якщо конкретний пакет містить лише ResearchLibrary.cmd, відкрийте його.
4. CheckInstallation.cmd запускає перевірку встановлених компонентів.

Ця тестова збірка ще не має підпису видавця. Назви файлів запуску та
попередня папка даних Universal Research Library збережені для сумісності.
Встановлюйте програму поза папкою з вашими дослідницькими даними.

КЛАВІАТУРА Й ЗБЕРЕЖЕННЯ

Інтерфейс поки англійською. Alt відкриває звичайне меню, Tab переводить
фокус між елементами. Ctrl+S зберігає поточну зміну; у відкритому редакторі
команда стосується саме його документа. У головному вікні Ctrl+Shift+S
запускає Save all changes і чекає підтвердження кожного збереження.
У відкритому голосовому читачі або студії для цієї ж дії доступна кнопка
Save all open drafts; Cancel Save All припиняє наступні збереження,
але вже збережені зміни залишаються. Дочекайтеся остаточного підсумку.
У голосовому читачі Ctrl+Shift+S залишається командою Save as.
Чернетки дослідницьких нотаток відновлюються через
File → Recover research-note draft або кнопку відновлення в нотатці.
Відновлення показує текст у редакторі; його потрібно окремо зберегти.

Options → Keyboard shortcuts дозволяє змінити клавіші.
Options → List current keyboard shortcuts показує фактичні призначення.
У читальному столі налаштування клавіш стосуються його власних команд:
переназначення зберігаються після закриття й повторного відкриття книги.
Початкові клавіші:
- Ctrl+Alt+K — налаштування клавіш;
- Ctrl+Alt+L — фокус на виборі бібліотеки або теми;
- Ctrl+Alt+S — фокус на повідомленні про стан;
- Ctrl+Alt+G — поточний поступ операції;
- Ctrl+Alt+P — новий аудіопроєкт;
- Ctrl+Alt+A — локальний помічник;
- Ctrl+Alt+J — збережені плани дій і завдання;
- Ctrl+Alt+V — голосовий читач;
- Ctrl+Alt+R — читання вибраної книги або її частини;
- Ctrl+Alt+Q — побудова розширеного запиту.

Insert і Caps Lock залишаються для екранного читача. Звукові повідомлення
про поступ типово вимкнені; їх можна налаштувати в Help. Повідомлення
про завершення фонової операції не повинно забирати фокус із результату.

ПРОГРЕС І СКАСУВАННЯ

Ctrl+Alt+G працює і під час тривалої операції. Автоматичне оновлення
індикатора не переводить фокус із поля, кнопки або результату читання.
Для кількох вибраних файлів програма показує кількість отриманих
результатів імпорту. Це не відсоток сторінок усередині поточного PDF.
Якщо обсяг роботи ще невідомий, індикатор залишається невизначеним.
100 відсотків означає підтверджене завершення, включно зі збереженням.
Перевірка OCR, помилка чи скасування мають окремий стан.

Cancel current operation припиняє подальшу роботу, коли поточний
компонент підтвердить скасування. Уже збережені книги залишаються
в бібліотеці. Після скасування наступні файли не імпортуються.
Якщо останній файл уже збережено, пізнє натискання Cancel не скасовує
успішний результат. Завжди прочитайте підсумок із переліком файлів.

Help → Progress sound settings містить Off, Beep, Speech та
Beep + Speech, гучність, інтервал, тихий режим і поведінку у фоні.
Для мовних підказок спочатку явно виберіть установлений голос
у вікні читання або студії та натисніть Use voice for progress.
Голос застосовується до поточного сеансу й поточної бібліотеки.
Короткі мовні підказки доступні українською, англійською та словацькою;
мова має відповідати вибраному голосу. Інші голоси залишаються доступними
для читання, якщо їхній установлений рушій підтримує потрібний текст.
Після зміни папки бібліотеки його потрібно вибрати знову.
Зміна режиму не завантажує й не встановлює голос автоматично.

Типове Off дозволяє користуватися повідомленнями самого NVDA без
подвійних звукових сигналів. За типових налаштувань підказки мовчать
під час відтворення; тихий режим вимикає їх повністю. Підказки
не додаються до майстра, розділів чи окремих доріжок аудіопроєкту.
Під час запису мікрофона програма утримує власні звукові підказки
в тихому режимі до підтвердженого завершення запису й очищення процесу.

ЗАВДАННЯ Й РЕСУРСИ

Tools → Tasks and resources показує збережені завдання та їхній стан.
Refresh оновлює список; Pause selected і Cancel selected доступні
лише для тих завдань, які підтримують ці дії. Прочитайте остаточний
стан після зупинки. Save allowances зберігає задані вами межі
одночасної роботи, пам’яті й диска. Це ваші дозволи, а не вимірювання
потужності комп’ютера. Продовжуйте завдання в його робочому вікні.

БІБЛІОТЕКА Й ДОСЛІДЖЕННЯ

Library → Import Center — файли, папки, черги та відновлення імпорту.
Для сканованих PDF вибирайте лише потрібні встановлені OCR-моделі.
Порядок кількох мов зберігається. Оригінали та перевірені цитати
залишаються відокремленими від нотаток, перекладів і тексту для озвучення.

Academic — бібліографія, списки читання, перевірка метаданих і цитування.
Research — пошук, збережені запити, теми та експорт дослідження.
Ctrl+R відкриває читання вибраної книги з позицією та закладками.

ГОЛОС І АУДІО

Voice → Voice reader and reading copy... (початково Ctrl+Alt+V) відкриває
окрему редаговану копію для озвучення. Дочекайтеся списку голосів,
виберіть установлений SAPI 5 голос і введіть короткий текст його мовою.
Для цього читання FFmpeg не потрібний. F6 читає, F7 ставить на паузу
або продовжує, F8 зупиняє. Save reading copy / Ctrl+S зберігає чернетку
для відновлення; Save as створює окремий читальний проєкт.
Нові голоси й нейромоделі автоматично не встановлюються.

ІНСТРУМЕНТИ ГОЛОСОВОГО ЧИТАЧА

Ctrl+F відкриває пошук, Ctrl+H — пошук із заміною. Find next і Find previous
переходять між збігами; Wrap search дозволяє повернутися на початок.
Можна враховувати регістр, шукати цілі слова або працювати лише
з виділеним фрагментом. Для шаблону ввімкніть Regular expression.
Спочатку натисніть Preview replace one або Preview replace all,
прочитайте зміни й виберіть Apply reviewed changes чи Reject preview.
Надто складний шаблон зупиняється без застосування заміни.
Undo у читачі скасовує прийняту операцію.

Ctrl+Shift+D відкриває Pronunciation dictionary. Додайте правило,
за потреби вкажіть мову або конкретний голос, установіть порядок правил.
Import dictionary і Export dictionary дозволяють переносити словник.
Preview pronunciation changes показує майбутню зміну тексту;
лише Apply reviewed changes застосовує її до читальної копії.
Оригінал книги й дослідницькі цитати залишаються незмінними.
Збережіть прийняті зміни копії через Ctrl+S.

Check spelling... відкриває перевірку правопису. Явно виберіть
Installed spelling language зі встановлених словників Windows,
натисніть Check passage, виберіть помилку та запропоноване виправлення.
Preview correction показує заміну; Apply reviewed correction
підтверджує її. Без потрібного встановленого словника програма
повідомить про це. Мова не підміняється, словники не завантажуються.

Reading appearance... змінює шрифт, колір тексту й тла та масштаб
від 50 до 400 відсотків. Перегляньте зразок і натисніть Apply appearance.
Cancel відхиляє новий вибір. Reset to system appearance готує
повернення до системного вигляду; його також підтвердіть через Apply.
Ці налаштування не змінюють тексту, виділення або змісту експорту.

Для вибору виходу в Windows натисніть Refresh outputs, виберіть
Reader output device і натисніть Use selected output. Сам вибір
не починає відтворення. Після нього натисніть F6 для читання
або F7 для продовження паузи. Якщо вибраний пристрій більше недоступний,
оновіть список і явно оберіть інший.

Усе це — початкові клавіші голосового читача. Keyboard shortcuts
у його вікні показує поточні призначення й дозволяє їх змінити.
Звичайне введення тексту та клавіші Insert і Caps Lock зберігають
своє призначення.

Audio Studio → New production — сценарій, ролі та збереження проєкту.
Audio Studio → Scene projects and saved scene jobs — наявні сценічні
проєкти й їхні завдання, збережені у попередньому форматі.
Audio Studio → Local voice engines — налаштування встановлених голосів.
Audio Studio → Scene voice and music engines — перегляд попередніх
реєстрацій рушіїв та їх повторне підтвердження після відновлення.
Audio Studio → Local music engines and sample — налаштування музичних
рушіїв, які ви вже встановили окремо.

FFmpeg не входить до передаваних Application ZIP і Sources ZIP.
Для функцій аудіостудії, яким він потрібний, відкрийте Audio Studio →
Local audio runtime setup... → Download and install reviewed runtime...
Перегляньте джерело, SHA256 й умови в діалозі та явно підтвердьте
завантаження, якщо згодні. Дочекайтеся повідомлення
verified and active for this library. Цей локальний пакет установлюється
окремо від програми й не додається до архівів доставки або резервної
копії бібліотеки.

Якщо точний ZIP або повна перевірена папка вже є локально, виберіть
Exact reviewed full-build ZIP або Existing complete runtime folder,
потім Browse local source... і Verify and select local source.
Під час роботи доступні Current operation progress (типово Ctrl+Alt+G)
та Cancel current setup. Прочитайте остаточний стан після скасування:
уже збережена реєстрація залишається збереженою.

Програма показує доступні локальні голоси. Зареєстрований голос або
музичний рушій ще не означає, що його якість перевірено. Відсутність
потрібного голосу чи мови має бути повідомлена, без непомітної заміни.

ЗАПИС І ДУБЛІ

Audio Studio → Record microphone and manage takes... відкриває запис.
Спочатку натисніть Refresh microphones, явно виберіть вхідний пристрій,
назву, частоту, один або два канали та граничну тривалість. Відкриття
вікна й оновлення списку не починають запис. Start recording запускає його.
Потрібний перевірений локальний FFmpeg із підтримкою DirectShow.

Stop and save recording завершує WAV, перевіряє його та зберігає оригінал.
Cancel unfinished recording відкидає незавершений запис. Close або Escape
чекає завершення очищення; уже збережені записи залишаються цілими.
Record retake of selected recording створює новий дубль, зберігаючи попередній.
Listen to saved recording явно вмикає прослуховування збереженого дубля.
Add to saved Studio project додає його до вибраного збереженого проєкту;
якщо проєкт уже відкритий у редакторі, відкрийте його повторно.

Цей запис ще не містить живого моніторингу входу чи повного редактора
звукової хвилі. Докладна інструкція — guides/recording.md.

ТРАНСКРИПЦІЯ

Library → Transcription: local audio and video спочатку пропонує
вибрати спосіб роботи з вашим локальним рушієм.

- Library workspace — strict receipts and optional word timestamps:
  відкрийте потрібну бібліотеку, підключіть отриманий сумісний рушій
  через «Підключити Whisper», додайте записи й виберіть наявну модель.
  Послівні часові мітки доступні лише за підтримки вибраного рушія.
- Reviewed local runtime profile — file checkpoints, pause and resume:
  відкрийте Manage local runtime, укажіть уже встановлені файли
  рушія та модель, натисніть Inspect files. Перегляньте результат
  і лише тоді підтвердіть довіру та Register trusted runtime.
  Виберіть цей профіль, записи, мову й формати результату;
  Start / resume починає або продовжує завдання,
  Pause at checkpoint просить зупинитися зі збереженням поступу.

Вибирайте спосіб, який підтримує саме ваш рушій. Уже збережене завдання
відкривайте тим самим способом: вибір іншого не перетворює його
автоматично. Порівняння варіантів є у файлі
TRANSCRIPTION_PROTOCOL_RECONCILIATION.md у документації до пакета.

Рушій, його залежності та моделі не входять до цього пакета автоматично.
Збережені завдання можна зупинити та продовжити; початкове аудіо,
результат розпізнавання й ваші правки зберігаються окремо.
Доступність додаткових можливостей залежить від підтвердженої версії
рушія. Докладна інструкція міститься в guides/TRANSCRIPTION.md.

Tools → Saved tool plans and jobs дозволяє додати транскрипцію до
переглянутого плану. Help у цьому вікні містить приклад audio.transcribe.
Спочатку підключіть перевірений локальний рушій, виберіть бібліотеку,
дозволені вхідну й вихідну папки та явно вкажіть наявну модель.
Перегляньте план через Preview і лише потім натисніть Run.
Після відновлення резервної копії повторно перегляньте рушій і створіть
новий план із поточними дозволами. Старий план не запускає рушій самостійно.

ПЕРЕКЛАД І ЗОВНІШНІ СЕРВІСИ

Tools → Translation and assistant service profiles — профілі перекладу
та служб планування. Збереження профілю саме по собі не виконує запиту.

Для Google Basic v2 потрібний ваш API-ключ. Для Advanced v3 виберіть
google-translation-v3, укажіть адресу свого числового проєкту й регіону
та Model ID general/nmt. У цій версії Advanced використовується ця модель.
Введіть OAuth access token і точний час його закінчення з часовим поясом.
Токен не оновлюється автоматично: після закінчення введіть новий
у тому самому профілі. Облікові дані не додаються до експорту профілів.

Tools → Translate selected text відкриває переклад похідної копії.
Виберіть точний обліковий запис, текст, діапазон читальних позицій,
цілий документ або явний список документів. Fetch languages запитує
підтримувані мови для вибраного профілю й моделі після вашого дозволу.
Перевірте окремо доступність мови оригіналу та мови перекладу.

Для Advanced v3 поле glossary можна залишити порожнім. Щоб застосувати
наявний глосарій, укажіть його повну назву ресурсу з того самого проєкту
й регіону; регіон має бути не global. Явно виберіть мову оригіналу,
без auto. Цей режим враховує регістр; програма не створює глосарій за вас.

Укажіть максимальний бюджет і, за бажанням, актуальний тариф вашого
договору. Preview показує точний текст, модель, глосарій та межі запиту.
Translate / resume потребує окремого підтвердження перед передаванням.
Після зміни тексту, мов, профілю або глосарія перегляньте умови знову.
Прийняті частини зберігаються; оригінал залишається окремо.
Read / narrate derivative відкриває Original, Translation або Bilingual.
Це робота з текстом: оформлення вихідного документа не переноситься.

ПЛАН ДІЙ: ПРОПОЗИЦІЯ, ПЕРЕГЛЯД, ЗАПУСК

Tools → Saved tool plans and jobs відкриває збережені плани й помічник.
Оберіть бібліотеку, дозволені вхідну та вихідну папки й введіть мету.
Planning source типово використовує Guided commands без звернення
до моделі. Для модельної пропозиції явно виберіть уже налаштований
локальний профіль. Програма не запускає сервер і не завантажує модель.

Preview plan готує пропозицію. Прочитайте кожну дію та вибрані папки.
Лише окреме Run / resume дозволяє виконання. Зміна мети чи меж роботи
скасовує попередній перегляд. Pause / Cancel proposal зупиняє запит.
Save named workflow зберігає план без виконання; Reuse saved workflow
потребує нового вибору меж, перегляду й дозволу на запуск.

РЕЗЕРВНА КОПІЯ

Library → Back up all libraries зберігає бібліотеки та підтримуваний
стан роботи, включно з незавершеними імпортами, чернетками й проєктами.
Створене аудіо можна включити окремо; необхідні вхідні матеріали
не повинні залежати від цього вибору. Моделі й облікові ключі
не стають частиною копії автоматично.
Збережені оригінали записів і зв’язки між дублями входять до копії
незалежно від вибору створеного аудіо. Незавершене тимчасове захоплення
не переноситься; після відновлення виберіть пристрій і почніть новий дубль.

Library → Restore backup to a new folder відновлює в нову папку.
Відновлені зовнішні запити, налаштування локальних рушіїв та старі
каталоги виводу потребують повторного перегляду. Перегляд збереженого
плану має працювати навіть за відсутності попередньої папки джерела.

НІЧОГО НЕ ПОЗНАЧАЙТЕ ЯК ВТРАТУ ДАНИХ ЛИШЕ ЧЕРЕЗ ПОМИЛКУ ЗАПУСКУ

Якщо установка або перевірка не завершилася, збережіть її повідомлення
та попередню папку даних. Новий пакет перевіряйте в окремій папці.
