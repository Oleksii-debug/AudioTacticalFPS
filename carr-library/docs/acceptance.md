# Resonance — release and capability acceptance

The [current technical specification](UNIVERSAL_SCOPE_V3_FINALIZATION.md) is the product authority. Root [AGENTS.md](../../AGENTS.md) governs coordination; claims and lane assignments are advisory. G/U gates retain library integrity requirements; V3 gates extend them to the whole platform. No speech/translation/transcription exclusion from the original Carr prototype applies to the current product.

Every verdict binds to an exact source/tree SHA, dependency/model pack identity, installed artifact hash, actual command/run and independent review. Track requirement, source review, adapter presence, integration, execution, quality qualification and distribution clearance separately. FAIL, NOT_RUN and missing-input states remain visible. Moving a branch, writing a document or completing an automation does not pass a product gate.

| Gate | Required evidence |
|---|---|
| G0 | Current scope, architecture/contracts, reuse/provenance decisions, advisory responsibilities and acceptance matrix |
| G1 | Real synthetic import → literal search → exact-source quotation → context → copy in the assembled application |
| G2 | Mixed/native/scanned documents, OCR and format isolation, editions/page mapping, duplicates, Unicode Windows paths, retry/cancel/resume |
| G3 | Exact raw-offset/citation integrity, scoped and semantic retrieval, held-out relevance metrics; no invented pages or quotes |
| G4 | Native keyboard workflow and actual NVDA evidence for the included capabilities |
| G5 | Clean installed Windows build, offline cold start, complete dependency identity, meaningful negative/security/recovery cases |
| G6 | Separately tracked acceptance of each lawfully supplied real corpus; absent Carr books block only Carr-specific claims |
| G7 | Declared deliverable/profile, exact artifact, all required gates for that scope, independent review, applicable distribution rights and signatures |

U1–U5 remain: independent libraries/collections; topic hierarchy/notes; immutable source evidence; scoped multilingual retrieval; exports and verified restoration without citation drift.

These group labels preserve prior traceability; record the precise requirement/scenario, not merely a group letter. Professional multitrack editing, microphone recording, reverb/chorus/de-esser or diarization is not passed by the presence of a generic audio or ASR module.

## Deliverable boundaries

- A development preview may expose a documented subset with pending modules clearly identified. It is not final platform completion.
- A qualified capability requires its real engine and actual outputs on a supported runtime/hardware profile.
- A distributable package requires exact applicable license/notices/source obligations and signed delivery evidence for that package, even when the recipient/channel is private.
- Full-platform completion retains all promised required capabilities. Future expansion or missing owner input is explicit, never silently deleted to make a gate pass.
- User-owned libraries, audio, transcripts and outputs remain readable/exportable/recoverable during network/license failures. Refresh cadence is distinct from offline validity.

## Required negative and recovery checks

Use meaningful cases for corrupt/unsupported archives, path traversal, malformed/large documents, missing model, wrong edition/offset/hash, Unicode paths, empty/ambiguous search, changed source/model/settings cache identity, output write failure, mid-job pause/cancel, crash after commit, disk-full, queue/backup restore, interrupted signed update and prolonged network outage. A failure in a final installed suite remains a failure even if earlier source suites passed.

Do not sum overlapping suite counts across runs or inherit results from another source/runtime. Preserve exact logs, test selection and exit codes. Manual NVDA, listening/native-language quality, actual optional models and legal-source review are separate checks. When execution is unavailable, record NOT_RUN and continue useful independent review; never fabricate evidence.
