# Resonance canonical integration checkpoint

This source checkpoint continues canonical `33dcc42edd6781b9aeb02dcaaf016b386bcf37b6`.
It preserves the current public implementation after a development-host outage.
It is not an installed Windows acceptance result or a complete platform release.

The integration retains the canonical application, voice registry, production
service, reading-document model, progress controller and state/pending backup
contracts. It adds the source-preserving extended-document adapters, shared
continuous reader, opt-in dordiai adapter, exact native launch entry and sealed
optional audio/citation runtimes. Version-5 extension and legacy-backup work is
in progress; old conflicting version numbers must never select a restore format
without authenticating its structure.

Focused suites were executed before the outage. They are not a single acceptance
count and must not be attached to reconstructed files or a different installed
artifact. The final integrated source, installed Windows probes, actual media
device behavior and private delivery still require their own evidence. Source
availability and synthetic protocol tests do not establish ASR/model accuracy,
voice rights, 135-language qualification, human NVDA or signed distribution.

Private supplied transcription source, binaries, model packs, recordings,
credentials and personal paths are excluded from this public checkpoint.
