This revision preserves the published [0d256381cdf4e059e1d8f2bdf8a06e6771ea57b9 composition](https://github.com/Oleksii-debug/AudioTacticalFPS/tree/0d256381cdf4e059e1d8f2bdf8a06e6771ea57b9/carr-library), tree `d4d1651881173301fa0bdcf7d96256d617b673ed`, from [PR97](https://github.com/Oleksii-debug/AudioTacticalFPS/pull/97), with narrowly reconciled source corrections described below. **Partial** means a concrete subset exists while complete acceptance remains open. **Not integrated** means no completed implementation of that requirement is established in this revision. No row is marked DONE.
