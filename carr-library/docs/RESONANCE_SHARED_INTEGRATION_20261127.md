## Resource contract

Allowances are cooperative declarations, not measured physical capacity, a
hostile-process sandbox, guaranteed inference peaks, or a scheduler for unrelated
applications. Whole configured CPU/RAM pools serialize the unmeasured supplied
ASR and managed production work. CUDA music/ASR requires an explicitly declared
device allowance; unknown automatic selection and inherited remapping are
rejected. Existing worker time, file, receipt and project disk limits remain.

Production disk estimates use explicit pauses, measured local sound duration,
the reviewed half-second-per-source-character estimate, and simultaneous
cache/mix/stem/export copies. They do not predict actual spoken duration.
Document admission declares the existing native parser's 3 GiB allowance and
separate library/scratch estimates. On Windows this is an admission declaration;
the POSIX address-space limit is not claimed there.

A standalone low-level render can receive its caller's broker explicitly;
the application Studio supplies its library coordinator. Stored output metadata
alone does not prove a live worker, accepted transcript or acoustic quality.

## Remaining acceptance boundaries

The canonical source-anchor compatibility bridge, remaining compatible Advanced
translation/local-planning changes and the final canonical branch convergence
are tracked separately. Real reviewed model inference, persistent model-session
performance, authorized cloning, acoustic/listening quality, Windows 11 NVDA,
and the exact language/runtime qualification matrix require their own evidence.
None is inferred from protocol doubles, native presentation fixtures, a
successful source suite or another commit's CI result.
