# Current Studio role and output controls

This component restores the canonical accessible role/voice and output-format workflow through the current Audio Studio owner. It keeps the current structured script, managed project, narration draft, save coordinator and backup schema. It does not copy the old alternate Studio or renderer.

The Script page now has **Edit roles and voices**. The Production page has **Final format and stems**. Both open the same named native form and require the existing **Structured production script** mode. Literal narration remains literal.

The form exposes exact installed voice/language choices, pan, native speech rate/pitch/volume, the existing final gain effect, all ten current output formats and separate stems. Unsupported speech controls remain disabled at their default; an inherited unsupported nondefault value must be reset explicitly. A saved unavailable or unlisted voice remains visible. An unlisted ID can be a retained engine alias, so its absence from enumeration is not described as proof that rendering is impossible. Editing that role still requires an exact advertised choice. Output-only changes may retain an unavailable role unchanged.

All edits are private until Apply. The resulting script must parse to the same complete production plan except for the explicitly selected role/output changes. Earlier effects, master processing, scene events, source words, sample rate and disk budget remain intact. Apply is one normal undoable draft edit; it invalidates the old render result and displayed preview. Saving and rendering remain separate explicit actions. Cancel and unchanged Apply preserve the previous draft and result.

The current controller, draft, project/source identity, displayed text/configuration, runtime selection, exact held voice registry and host authority are checked again after discovery and modal acceptance. Native construction failures destroy their owned form. Focus returns only to a live control in the same current Studio.
