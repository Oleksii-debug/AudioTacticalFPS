## Interrupted work and publication

The assistant persists preparation and run dispatch before invoking the respective non-idempotent domain actions. An unbound preparation or a dispatched run without accepted completion requires attention and a new reviewed plan. It never adopts a same-byte orphan or silently starts another inference. Accepted completion is recovered through the current retained receipt verifier.

Exports contain selected transcript formats and separate provenance in one new, exclusively published directory. Exact parent and stage identities, sealed inventories, and per-file SHA-256 allow recovery of owned partial work. Foreign same-byte files do not grant ownership. A stop after the complete publication remains a committed result. Empty transcripts remain valid silence.
