## Limits that remain explicit

Canonical long-lived Dordiai adapter tests include retaining a warm worker after cancel/drop and reusing the same process after successful calls. The current adapter owns and settles a process per utterance. Existing synthetic current tests cover catalogue/resource policy, exact JSONL PCM, cancellation, malformed replies, blocked stdin and owned descendants. They do not establish the old warm-worker lifecycle or its performance.

Current profile registration is explicit and local to its library. Old schema1 bytes and historical voice IDs remain inert; they cannot activate an external path or acquire current execution authority. Native SAPI uses the already pinned pywin32 client and preserves current voice identities. Its 22050 Hz PCM is distinct from historical 24 kHz PowerShell receipts. Current Flite is 24000 Hz, while canonical raw tests expected 22050 Hz. Current PCM16, 8000-character and 256 MiB segment limits are not presented as an alias for every old configurable SpeechSettings call.

Earlier ASR state retains complete original bytes, accepted results, edits and provenance. Component e087 restores exact canonical cache-inclusion refusal and 32 GiB-per-source / 64 GiB-total historical input retention. Current new library-wide jobs retain their separate 32 GiB aggregate execution limit; older workspace profiles retain 8 GiB-per-source / 32 GiB-batch. No 64 GiB throughput or private model quality was measured. Old package execution/cache-rebind APIs are not invoked on recovered historical jobs.

Selected local runtime admission uses current complete pinned manifests and regular-file rules. This does not inherit the old permissive final executable symlink and auto-discovered base-runtime policy. Packaging likewise uses the current explicitly selected pinned-archive setup and sealed bundle, not an imported duplicate acquisition/manifest framework. The old acquisition helper's redirect and reuse tests are not called current test results.

Registered progress qualification uses actual native selectors, root changes, worker cleanup and passive backup with notification audio Off. Its 16 checks do not prove actual speech/device output. Bytecode protections are covered by current child arguments, actual child/import tests and sealed installation/inventory boundaries; the removed old-package sentinel tests were not executed unchanged.
