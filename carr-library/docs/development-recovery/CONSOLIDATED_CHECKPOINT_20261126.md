## Product boundary

The updated specification still requires owner-reviewed signing/private delivery,
private entitlement and signed-update integration, authorized owner-supplied
cloning engines, actual optional neural-model inference, SAPI4 compatibility,
human Windows11/NVDA/listening acceptance and the final 135-entry capability

135 working or acoustically qualified voices. Actual long streaming fixtures
are explicitly different from full-length original neural generation.

Standalone transcription awaits the separately supplied owner project and is
outside the current core-delivery gate. Private code, model weights, recordings,
credentials and user documents are not included in this source checkpoint.
