# Integrated books, structured translation, local schedules and selected Calibre

This source continuation composes existing services rather than replacing their
runtime or source authority. New source requires actual exact-head acceptance;
a source review or a candidate commit is not an executed test.

## Product behavior

- Ordered book batches prepare current managed Studio projects with exact source
  anchors and explicit output review. Existing completed parts are hash-verified
  under their current project lock and can export after full backup/restore
  without discovery of archived voice/model/FFmpeg paths. Unfinished parts still
  use the current renderer, resource broker and process owner.
- Structured Google Basic/Advanced translation retains document order, original
  sections, paragraph boundaries and tested Markdown heading/code structure.
  Current selected sources are revalidated before each remote chunk. Accepted
  receipts remain durable; cancelled source validation does not invent an
  uncertain remote charge. All source hashing/submit runs on the shared worker.
  CLI preview/queue/run/export requires exact explicit profile/review/job approval.
- The current assistant has typed reader/evidence/conversion/voice/plan/effects/
  player operations, plus explicit local schedules for existing approved plans.
  Saved time slots are inert until armed for the current foreground session;
  restoring or reopening cannot reactivate execution.
- Optional selected Calibre conversion admits eight declared legacy ebook
  families through the existing conversion worker. The chosen executable,
  frozen core and runtime identities remain held until the existing native
  process family is quiet. No runtime, model, credentials or proprietary book
  is embedded in this source.
- The exact current canonical export correction rejects a stale destination
  approval before opening or hashing a different user-selected target.
